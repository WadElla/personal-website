abstract: IoT Shepherd is an agent-orchestrated framework for secure IoT ecosystem management. It combines retrieval-augmented reasoning over device documentation with transformer-based anomaly detection, allowing an LLM agent to connect device-specific context, traffic incidents, and mitigation guidance. The system is designed to support both routine administration and incident response by grounding operational answers in retrieved evidence instead of unsupported model knowledge.
